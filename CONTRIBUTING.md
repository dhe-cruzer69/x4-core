# Contributing to x4-core

Thank you for your interest in contributing to the X4 ecosystem.

## Development

1. Fork and clone
2. Create a feature branch
3. Install dependencies
4. Make changes with tests
5. Open a pull request

## Code Style

- Prefer clear, typed interfaces
- Keep the core surface small and stable
- Document public APIs

## Pull Requests

- Link related issues
- Include tests for new behavior
- Update CHANGELOG.md
- Ensure CI passes

## Code of Conduct

Be respectful. Harassment or abuse will not be tolerated.
