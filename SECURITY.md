# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.x     | :white_check_mark: |

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Email or use GitHub private vulnerability reporting.

We aim to acknowledge reports within 72 hours.

## Scope

This project is early-stage infrastructure. Treat all releases as experimental until v1.0.
