# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Email or use GitHub private vulnerability reporting for this repository.

Include:
- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We aim to acknowledge reports within 72 hours.

## Security Principles (X4)

- Least privilege by default
- Explicit permission checks before tool execution
- No unrestricted production credentials for agents
- Immutable audit logging of sensitive actions
- Dependency and secret scanning enabled
